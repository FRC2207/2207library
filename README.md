# Team 2207 Reusable FRC Code
This is our code base for keeping an example project for future robots. The purpose of this is to be a clone of the previous robot code that can be developed over the offseason and forked for the upcoming season.

Features:
- [RoboRoute](https://github.com/FRC2207/RoboRoute) On-the-fly path drawing using an android tablet
- Advantage Kit Logging
- PathPlanner Pathfinding
- Object Detection using iSpy (https://github.com/aidan-j532/iSpy-FRC)
- PhotonVision Apriltag Localization
